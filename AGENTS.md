# Development guidance

## Scope and source of truth

- Use Node.js 24.x for local development.
- Edit extension code in `src/extension*` and webview code in `src/webview`.
- Files such as `assets/academic/*.js` are generated by `npm run compile`; do not
  hand-edit them.
- Keep `manual-tests/` for interactive fixtures and `test/` for independently
  invoked automated tests.

## Verification

- Run `npm run check` for a clean build, TypeScript checks, and ESLint.
- Run `npm test` explicitly when relevant. Do not add tests to `build`,
  `vscode:prepublish`, or another routine packaging path.
- Launch the Extension Development Host with `F5`; the launch configuration
  enables `customEditorDiffs` and opens `manual-tests/`.
- Inspect release contents with `npx @vscode/vsce ls --tree` before packaging.
- Do not add GitHub Actions unless the maintainer explicitly requests them.

## PDF.js vendoring

- Runtime PDF.js files must remain bundled so installed extensions work fully
  offline. Never load PDF.js, its Worker, fonts, CMaps, or WASM from a CDN.
- `assets/pdfviewer/vendor.json` is the machine-readable version record.
- Use `npm run pdfjs:check` to query the latest official release without
  changing files.
- Use `npm run pdfjs:update -- --version x.y.z` for an explicit, checksum-verified,
  staged update. Never replace `assets/pdfviewer/lib` manually.
- Use `npm run pdfjs:verify` for an offline vendor-layout and version check.
- Keep `assets/pdfviewer/lib/pdf.css`; it is extension-owned. The updater omits
  source maps, debugger/example assets, and the unused scripting sandbox.
- After any PDF.js update, run the independent automated checks and manually
  verify normal PDFs, long PDFs, CJK text, forms, link previews, Git diffs,
  changed-region highlights, and VS Code shortcut routing.

## Change discipline

- Keep changes narrow and preserve unrelated worktree modifications.
- Treat Proposed API behavior as version-sensitive and test it in a compatible
  VS Code build with Proposed API access enabled.
- Do not weaken the webview CSP or re-enable PDF JavaScript evaluation without
  an explicit security review.
